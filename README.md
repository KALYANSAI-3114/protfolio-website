# Kalyan Sai — Bright AI Engineer Portfolio V2

A completely redesigned bright portfolio using:

- HTML
- CSS
- Vanilla JavaScript
- Bento project layout
- Bright purple/orange/cyan visual system
- Large editorial typography
- Floating AI UI elements
- Responsive mobile layout
- Scroll reveal animations
- Working GitHub links
- Mailto contact CTA
